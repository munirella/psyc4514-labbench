The order the trials run in

A row is not a trial. The file says what kinds of trial exist; the loop decides how many times each kind runs and in what order. Every column you add to the file shows up as a column in your data, which is how you get the condition labels back out at analysis time.

Durations that always land exactly

This is why 220 ms is not a duration. Pick from the safe list, or accept that you are really asking for the nearest one. It matters less than you might think for a single stimulus — but it matters a great deal when you report what you presented, and when someone tries to replicate it.
